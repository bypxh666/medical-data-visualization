# 医疗健康行业数据可视化

基于 **Vue 3 + ECharts** 的医疗健康行业数据可视化大屏，覆盖出诊、急诊、收费、销售、客流、用药等典型场景，以图表形式直观呈现医疗运营数据，辅助分析与决策。

> 医疗数据正以指数级增长：据 Statista 统计，全球医疗数据量已从 2013 年的 153 艾字节增长到 2020 年底的 2314 艾字节。数据分析与可视化正成为医疗健康领域预防、预测疾病的重要课题。

## 功能

- **6 类医疗场景可视化**：号别出诊占比、科室急诊次数（玫瑰图）、科室门诊收费、门店销售额、药店客流走势、药品购买/开卡趋势
- **多图表类型**：饼图、南丁格尔玫瑰图、柱状图、横向条形图、折线图、柱线组合图
- **响应式布局**：桌面端双栏、移动端单栏，窗口缩放时图表自适应
- **组件化架构**：通用 `BaseChart` 组件统一管理 ECharts 生命周期（初始化、resize、销毁），图表配置与数据抽离到数据层，便于维护与扩展

## 技术栈

| 层 | 技术 |
| --- | --- |
| 框架 | Vue 3（`<script setup>` 组合式 API） |
| 图表 | ECharts 6 |
| 构建 | Vite 7 |
| 语言 | JavaScript |

## 目录结构

```text
medical-data-visualization/
├── index.html                    # 入口 HTML
├── src/
│   ├── main.js                   # 应用入口
│   ├── App.vue                   # 主界面：标题 + 响应式图表网格
│   ├── style.css                 # 全局样式（布局、卡片、响应式）
│   ├── data/
│   │   └── chartOptions.js       # 6 个图表的配置与数据（数据层）
│   └── components/
│       └── BaseChart.vue         # 通用 ECharts 图表组件
└── vite.config.js
```

## 快速开始

```bash
# 安装依赖
npm install

# 本地开发（默认 http://localhost:5173）
npm run dev

# 生产构建
npm run build

# 预览构建产物
npm run preview
```

## 图表说明

| 图表 | 类型 | 内容 |
| --- | --- | --- |
| 不同号别的出诊次数 | 饼图 | 普通 / 专家 / 知名专家出诊占比 |
| 某医院科室急诊次数指标分析 | 玫瑰图 | 各科室急诊次数分布 |
| 不同科室的门诊收费金额 | 柱状图 | 10 个科室收费金额对比 |
| 不同门店的销售额 | 横向条形图 | 10 家门店销售额排名 |
| 近 10 天药店来访人数走势 | 折线图 | 客流随时间变化趋势 |
| 不同药品的购买次数和开卡数 | 柱线组合图 | 购买次数与开卡数双指标 |
